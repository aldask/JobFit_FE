# JobFit

JobFit is a FullStack (React + FastAPI) app that helps a user tailor a resume and generate a cover letter for a specific job post.

The frontend collects:

- A pasted job description.
- A PDF resume.

It sends both to the FastAPI backend then shows:

- An improved resume draft.
- A cover letter.
- Bold keyword matches in the resume when a job requirement also appears in the generated resume.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- FastAPI
- Gemini API

## Setup

Install dependencies:

```
npm install
```
